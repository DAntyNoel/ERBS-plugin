# 八维玩家风格雷达

本目录将雷达功能拆成四层：

- `data.py`：分页读取 DAK.GG 排位三排单局，过滤模式、去重并聚合行为指标。
- `scoring.py`：八维算法、指标权重、校准中点和 0–100 分转换。
- `models.py`：数据样本、指标、维度分数和最终画像的数据结构。
- `presentation.py`：把最终分数转换成渲染器需要的八边形 SVG 坐标。

## 统计口径

默认使用最近 20 场 `RANK + SQUAD`。累计数值优先转换为每分钟、每 10 分钟、
每场或占比，再进入评分，避免长局天然获得更高分。重复 `gameId` 会被去除；最多可
读取 60 场。

八个维度分别是：

1. 进攻性：玩家伤害密度、击杀密度、PVP 输出占比。
2. 承压性：玩家承伤密度、自我治疗与护盾承伤。
3. 团队参与：参团率、助攻密度、队友复活。
4. 控制支援：控制时间、治疗护盾、战术技能使用。
5. 发育运营：动物击杀、野怪伤害、刷野信用币占比。
6. 视野控图：视野贡献、摄像头、控制台与侦察工具。
7. 资源投入：信用币周转、消费密度、高阶制造。
8. 稳健性：死亡密度、多次死亡对局率、无死亡对局率。

`teamDown`、`teamElimination` 和 `terminateCount` 是团队字段，不进入个人雷达；MMR、
胜率、Top 3 和平均排名属于结果指标，也不进入风格评分。

## 分数转换

每个基础指标使用分段线性校准：

```text
0 -> 0 分
midpoint -> 50 分
upper -> 100 分
```

超过 `upper` 截断为 100。死亡密度等反向指标再执行 `100 - score`。维度原始分是基础
指标的加权平均；最终分还会按样本量和字段覆盖率向 50 分收缩：

```text
reliability = min(1, sample_size / 20) * field_coverage
final = 50 + (raw - 50) * reliability
```

因此 50 是当前 `style-v1` 校准中点，分数表示行为倾向而不是能力高低。默认校准集中在
`DEFAULT_SCORING_PROFILE`，后续可替换成按版本、段位或角色计算的动态基准，而无需修改
数据获取和渲染代码。
